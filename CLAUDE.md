# Имперский архив

Лист персонажа для Warhammer Fantasy Roleplay 4, на русском, офлайн.
Ванильный JS без сборщика, Capacitor поверх — APK. Зависимостей у самого
приложения нет и не должно появиться.

## Сеттинг — читать до правки текстов

**`LORE.md` — обязателен к прочтению перед любой правкой пользовательских
текстов, названий и оформления.** Там же таблица «нельзя / вместо этого».

Коротко, чтобы не переспрашивать: это **Warhammer Fantasy**, Империя,
Рейкланд, 2512 ИК. Это **не Warhammer 40 000**: ни «Империума», ни «Ордо»,
ни Инквизиции как организации, ни уровней допуска. Игровые данные из книги
(карьеры, таланты, заклинания) по `LORE.md` не правятся — книга главнее.

### Поправлять собеседника — часть работы

Если человек в разговоре путает сеттинг — говорит «Империум» про Империю,
относит к Фэнтези то, что из 40k, называет неверную дату или бога не с тем
покровительством — **скажи об этом сразу, до того как выполнять просьбу**.
Коротко, по делу, без нотаций: в чём ошибка, как правильно, и дальше по
задаче. Промолчать здесь — значит закрепить ошибку в приложении.

То же и в обратную сторону: если уверенности в факте нет, так и сказать.
Правдоподобная выдумка про сеттинг хуже честного «не помню точно».

## Проверки

Ни одна правка не считается готовой без них:

```
node scripts/audit.mjs           # статика: мёртвый код, осиротевший CSS, чужой лор
node scripts/check-features.mjs  # поведение, 167 проверок
node scripts/check-app.mjs       # обход экранов, контраст, зоны нажатия
```

Аудит валит сборку на словах из 40k в собственных текстах приложения.
Технические идентификаторы с «ordo» он пропускает намеренно — см. `LORE.md`.

Новая возможность — новая проверка. И проверку надо **сломать назло** и
убедиться, что она краснеет: зелёная проверка, которая ничего не проверяет,
хуже её отсутствия. В этом репозитории такое уже случалось дважды.

## Как здесь принято

- **Ничего не выпускать без записи в `CHANGELOG.md`.** `scripts/release-notes.mjs`
  собирает из неё описание релиза и отказывается работать, если записи нет,
  разделы не по Keep a Changelog или номер версии не отвечает содержимому
  (патч с «Добавлено» не пройдёт).
- **Добавил файл на страницу — впиши его в `ASSETS` в `sw.js` и подними
  `CACHE`.** Иначе офлайн отдаст старое.
- **Не переходить на ES-модули.** В разметке живут инлайновые обработчики,
  они разрешаются только в глобальной области; `type="module"` убьёт их все
  на первом же нажатии.
- **Хранилище не трогать.** Ключи `wfrp4_roster_v1`, `wfrp4_sheet_v1`,
  `wfrp4_currentstate_v1`, `wfrp4_theme` — старые сохранения обязаны
  открываться.
- **`applicationId` не менять** — он зафиксирован публикацией.
- Комментарии по-русски и объясняют **почему**, а не что.

## Выпуск

Тег из сессии Claude Code не создать — GitHub отбивает 403 на теги и на
удаление веток. Выпуск идёт через `workflow_dispatch` у `android.yml` со
входом `tag`: `gh release create` внутри сборки делает тег своим токеном.
