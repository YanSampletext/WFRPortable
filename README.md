# Досье Ордо

Одностраничное приложение для создания и ведения персонажа
**Warhammer Fantasy Roleplay 4** (русский язык). Работает офлайн, данные
хранятся в браузере (localStorage), есть экспорт/импорт JSON.

## Возможности
- Мастер создания по Книге игрока: народ → карьера → характеристики
  (броски / перестановка / 100 очков) → 5 стартовых шагов по схеме карьеры →
  судьба → 40 шагов навыков + талант → имущество (автовыдача) → детали
- Магазин XP: цены по книге, схемы 64 карьер, ×2 вне карьеры,
  строгое завершение ступеней (5/10/15/20)
- Бой: таблицы критических ран (5 зон), заминки «Ой!», проверка смерти,
  трата Судьбы, печать «Мёртв»
- Здоровье: состояния, увечья, болезни (9 из книги), восстановление
  (сон / отдых / зелье), психология (страх, ужас, бешенство)
- Магия и вера: заклинания, каналирование, ошибки, молитвы, гнев богов
- Журнал бросков, печати ГМ, светлая/тёмная тема, мобильная вёрстка

## Структура
```
index.html      каркас
css/            base, reskin (грим-тема), marks (печати), ui-fixes
js/app.js       ядро: данные, мастер, бланк, магазин
js/schemes.js   схемы развития карьер
js/crit.js      критические раны
js/diseases.js  болезни
js/psych.js     психология + заминки
js/health.js    восстановление + проверка смерти
js/marks.js     печати и отметки ГМ
js/storage-native.js  дублирование персонажей в хранилище приложения
manifest.json   PWA
sw.js           service worker (офлайн-кэш)
fonts/          шрифты Google, зашитые локально (css/fonts.css)
scripts/        сборка www/ и запуск gradle
android/        Android-проект Capacitor (см. BUILD-ANDROID.md)
```

## Запуск
Открыть `index.html` в браузере — всё. Веб-версия живёт на GitHub Pages
(Settings → Pages → deploy from branch).

## Приложение для Android
Готовый APK — во [вкладке Releases](../../releases/latest).

Сборка своими руками: `npm run apk`. Capacitor зашивает сайт целиком
внутрь пакета — приложение работает без интернета и не зависит от Pages.
Подробно, включая ключ подписи и переезд данных:
[BUILD-ANDROID.md](BUILD-ANDROID.md).
